# Apresentação: RTX PRO 6000 Blackwell

Tour 3D interativo e cinematográfico de uma placa de vídeo NVIDIA RTX PRO 6000 Blackwell. A placa é apresentada, se desmonta peça a peça, e a câmera aproxima de cada uma enquanto uma linha de chamada leva a uma explicação detalhada.

Peças sem documentação pública são apresentadas como **arquitetura provável**, com selo de procedência (`confirmed`, `derived`, `inferred`, `illustrative`), para deixar claro o que é fato e o que é proposta de engenharia.
